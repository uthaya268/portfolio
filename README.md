# Uthaya Kumar M — Portfolio Website

## Run locally
1. Extract `Uthaya_Kumar_Portfolio.zip`.
2. Open `index.html` in a browser.

The portfolio is a responsive static website. It uses the profile photo and résumé PDF in `assets/`.
To publish it, upload the folder to GitHub and enable GitHub Pages, or deploy it using Netlify or Vercel.

## Personal details to review before publishing
- Confirm the email address and phone number.
- Add GitHub / LinkedIn links if you want them displayed.
- Add live project links when your projects are deployed.
